gauntlet‑verify

For work that cannot afford to be mediocre or wrong. Build to a shipped bar, and check every claim with agents that never saw your reasoning.

Get the skill Read SKILL.md
Two modes. Three formations. A ceiling written before it spends.

A rubric is a lossy copy of the bar.

It works when the criteria are mechanical and fails when the quality is experiential: a page that feels expensive, a deck that lands, prose that does not read as generated.

So the skill does not write criteria. It names an artifact that already clears the bar, and it seats agents that never saw the build to say where the gap is.

The request picks the mode.

REFERENCEPoint it at a shipped thing you want to match. An isolated critic and blind judges run until the judges can tell your build from the original only by brand, age or adoption, never by craft.
VERIFICATIONPoint it at research that has to be right. Agents that never saw your reasoning try to kill every load-bearing claim, and each claim ships labeled.

A seat is one isolated agent role. A formation is how many seats a job gets. A ceiling is the budget in rounds or tokens.

Reference mode runs the gauntlet.

  1. Name a specific shipped reference and write the ceiling. "Linear's settings page" passes. "Good design" does not.
  2. An isolated critic names the gaps, each mapped to one area and one edit. No praise.
  3. Fix, and snapshot every round, so a regression goes back to whoever caused it.
  4. Blind judges see both artifacts unlabeled, in both orders, and say which is the attempt and what gave it away.
Craft tell: spacing, copy, motionnext round's brief
Identity tell only: brand, age, adoptiondone, ship it
Two rounds with no drop, or the ceilingpark the best snapshot

Verification mode tries to kill every claim.

Verifiers get the claims and where each came from, never the reasoning that produced them. They answer the open question first, trace to the primary source, recompute, re-fetch, and check the date.

Every claim leaves with one label. Pick one.

A claim is split into atomic facts first, and it is verified only if every fact is. Conflicting figures are never averaged.

Spend follows consequence.

The stakes test decides between light and the rest. Who sees the result decides between medium and full. Your word overrides it either way.

You are the brake.

There is no round cap. A round that would pass the ceiling, judged by spend so far plus the last round's cost, does not start.

Two rounds in a row with no drop in open tells is a stalled loop. It stops and reports. At any stop short of Done, the best snapshot ships, not the last.
